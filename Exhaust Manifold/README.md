# 4-into-1 Exhaust Manifold

A 3D mechanical model of a 4-into-1 exhaust manifold designed for a 4-cylinder engine. The geometry features flat mounting flanges, multi-axis swept primary tubes, and a merged exhaust collector.

**Design Tools:** SolidWorks 2024 (Boss-Extrude, Swept Boss/Base, Cut-Extrude).

**Files:** `.SLDPRT` (Native CAD), `.STEP` (Universal 3D), and `.JPG` (Render Preview).
