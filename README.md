# SolidWorks Mechanical Design Portfolio

Welcome to my 3D CAD portfolio. This repository contains a collection of mechanical parts, assemblies, and design methodology exercises created using **SolidWorks**. 

## ⚙️ About This Repository
As a mechanical engineering student, I use this repository to document my CAD skills, highlighting my ability to create clean geometries, utilize proper design trees, and prepare models for manufacturing or simulation. 

**Software & Tools:**
* SolidWorks 2024 (Parametric Modeling, Assemblies)
* Formats provided: `.SLDPRT`, `.STEP` (Universal CAD), and `.JPG` renders.

## 📂 Project Highlights

* **CAD Methodology Exercises:** A series of models demonstrating progressive skill in feature management, sketching, and complex geometry generation.
* **Model Mania 2003 & 2004:** Replications of the famous SolidWorks modeling challenges, focusing on design intent and modeling efficiency.
* **Sheet Metal Design (MarSheetMetal):** A protective enclosure model demonstrating proficiency with SolidWorks sheet metal tools, including base flanges, edge flanges, corner reliefs, and feature cutouts.

## 📥 How to View the Files
Recruiters and engineers can view the `.JPG` renders directly in your browser by clicking into the folders above. 
To inspect the 3D models, download the `.STEP` files, which can be opened in any major CAD software (SolidWorks, AutoCAD, Inventor, Fusion360).
