# Sheet Metal Enclosure Cover (MarSheetMetal)

A 3D mechanical model of a protective sheet metal enclosure. The design demonstrates proficiency in sheet metal fabrication techniques, featuring bent flanges, custom mounting tabs, edge treatments, and feature cutouts.

**Design Tools:** SolidWorks 2024 (Base Flange/Tab, Edge Flange, Cut-Extrude, Break Corner).

**Files:** `.SLDPRT` (Native CAD), `.STEP` (Universal 3D), and `.JPG` (Render Preview).
