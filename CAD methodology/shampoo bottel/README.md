# Shampoo Bottle Packaging (Surface Modeling)

A 3D mechanical and industrial design model of a contoured shampoo bottle with a matching detachable cap. This project demonstrates advanced surface modeling techniques used to create organic, consumer-friendly packaging shapes.

**Design Tools:** SolidWorks 2024 (Surface Sweep, Surface Trim, Surface Knit, Surface Offset, Split Line, Mirror).

**Files:** `.SLDPRT` (Native CAD), `.STEP` (Universal 3D), and `.JPG` (Render Preview).
