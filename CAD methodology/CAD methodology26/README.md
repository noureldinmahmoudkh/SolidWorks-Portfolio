# Ergonomic Turn Knob (CAD Methodology 26)

A 3D mechanical model of a smooth, contoured handle designed for manual turning applications, featuring an ergonomic oval grip and a tapered neck. 

**Design Tools:** SolidWorks 2024 (Loft, Thin Revolved Cut, Extrude).

**Files:** `.SLDPRT` (Native CAD), `.STEP` (Universal 3D), and `.JPG` (Render Preview).
