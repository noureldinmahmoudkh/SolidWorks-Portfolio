# Mechanical Linkage Arm (CAD Methodology 20)

A 3D mechanical model of a linkage arm featuring a weight-optimized pocketed center and dual mounting bores. This model utilizes a SolidWorks Design Table to drive multiple geometric configurations (B, C, D) from a single base file.

**Design Tools:** SolidWorks 2024 (Design Tables, Configurations, Extrude, Cut-Extrude, Fillets).

**Files:** `.SLDPRT` (Native CAD), `.STEP` (Universal 3D), and `.JPG` (Render Preview).
