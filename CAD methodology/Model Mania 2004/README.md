# Model Mania 2004 Challenge

A 3D mechanical model replicating the SolidWorks Model Mania 2004 design challenge. The geometry features drafted outer walls, a stepped contoured profile, and a shelled interior structure.

**Design Tools:** SolidWorks 2024 (Boss-Extrude, Cut-Revolve, Draft, Shell, Fillets).

**Files:** `.SLDPRT` (Native CAD), `.STEP` (Universal 3D), and `.JPG` (Render Preview).
